# TASK 3: PASSWORD GENERATOR

# 📝 PROJECT DESCRIPTION
A robust Python-based tool designed to generate strong, random passwords. This application allows users to specify the desired length and complexity of their passwords to enhance their digital security.

# PROJECT VIDEO
https://github.com/user-attachments/assets/d0669e17-e407-4470-abb1-4c42fe925d3e

# ✨ KEY FEATURES
* Custom Length: Users can define exactly how many characters the password should have.
* Complexity Control: Options to include uppercase letters, lowercase letters, numbers, and special symbols.
* User-Friendly Interface: Clear prompts and instant password generation.
* Security Focused: Generates unique strings that are difficult to crack via brute force.

 # 🛠️ TECH STACK
Language: Python 3.x
Libraries:
random: To ensure password unpredictability.
string: To easily access sets of characters (letters, digits, punctuation).
Tools: VS Code, Git, GitHub

# HOW TO RUN
* Clone the repository.
* Navigate to the TASK1 : CALCULATOR folder.
* Run python calculator.py.
