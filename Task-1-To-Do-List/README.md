 # Project Description
A simple and efficient To-Do List application built using Python to help manage daily tasks.

# Features
1. Add new tasks
2. View current list
3. Remove completed tasks
4. Exit from the list

 # 🛠️ Tech Stack
* Language: Python 3.x
* Libraries: Tkinter (for GUI) / OS & JSON (for storage)
* Tools: VS Code, Git, GitHub

  # HOW TO RUN :
Clone the repository.
